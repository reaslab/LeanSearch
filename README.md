# LeanSearch

The code for [A Semantic Search Engine for Mathlib4](https://arxiv.org/abs/2403.13310) is hosted at [https://github.com/frenzymath/LeanSearch](https://github.com/frenzymath/LeanSearch). The dataset is available at [https://huggingface.co/datasets/FrenzyMath/mathlib_informal_v4.16.0](https://huggingface.co/datasets/FrenzyMath/mathlib_informal_v4.16.0).
